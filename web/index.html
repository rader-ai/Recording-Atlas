How the system works

From transcript to evidence

01 / Preserve the source

Validate ordered cues and group them into overlapping passages with timestamps.

02 / Index only changes

Compare content hashes, enforce the input budget, and commit a complete index atomically.

03 / Retrieve in parallel

Combine keyword and vector rankings. Keep keyword search available when the vector service fails.

04 / Make review possible

Return exact excerpts and source references. Open any passage to inspect its surrounding context.

Honest scope. Default vectors use a small, transparent concept fixture, not a trained model. The Python project includes an optional OpenAI embedding adapter. This is retrieval with citations, not generated answers.

All transcripts were authored for this demonstration. No private recordings, customer data, credentials, or repository history are included.
