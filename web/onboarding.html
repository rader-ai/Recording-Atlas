Computer requirements

Python 3.11 or newer, a current browser, and writable local storage. No GPU is needed for cloud processing.

Audio imports require FFmpeg with ffprobe on your system PATH. Restart this application after installation. Transcript imports do not need FFmpeg.

Get Python · Get FFmpeg for your operating system

Install Python and FFmpeg using the instructions for your operating system. In a terminal, confirm python3 --version and ffprobe -version work. On Windows, use py -3 instead of python3 if needed.

Runs on your computer. Credentials entered here stay in server memory and must be reentered after restart. Imported content is saved locally.

Start with something meaningful.

Website discovery reads links and embeds from one public HTTPS page. Playlists show up to 100 entries. Select one recording, then attach its transcript or media. Automatic YouTube caption access is not included.

WebVTT or media up to 20 MB with OpenAI, or 50 MB in local mode. Media requires FFmpeg with ffprobe and must be 90 minutes or shorter. Larger recordings need compression or an exported transcript. WebVTT cues must be ordered without overlap.

Drafts preserve source wording and require your review. This first version normalizes transcript spacing; it does not rewrite the teaching. Question generation supports up to 60,000 transcript characters.
